# Dægradvöl

Every day of a life on one screen — 14 Feb 1996 to 13 Feb 2077, one row per year.

- Days lived / left, live countdown
- Tap any day for its number, date, age and projected strength total
- Anniversaries, the girls turning 18, pension ages, strength milestones
- Installable PWA, works offline

Hosted on GitHub Pages. To install on Android: open the site in Chrome → menu → *Add to Home screen* / *Install app*.
